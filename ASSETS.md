# Asset notes

- `game/assets/arcade-sheet.png`: the artwork sheet supplied by project maintainer
  s3pp3ku as “Omarchy Lunatic Fringe Arcade Asset Sheet.png”. This supplied image
  is retained unchanged. No artwork was extracted from the original After Dark
  game. The image is separate from the MIT code license; contact the maintainer
  for artwork reuse outside this project.
- The Omawing player ship uses its supplied artwork-sheet sprite. The small bar
  icon is original vector geometry in this repository and covered by the code license.
- All sound clips are synthesized by `game/sound.py` and covered by the code
  license. No third-party audio recordings are included.
- `docs/gameplay.png` is a render from this game, including the supplied sheet.
